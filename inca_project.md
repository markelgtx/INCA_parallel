This is the documentation for **INCA** (Intracule Calculator). 

This code parses `.fchk`, `.wfx`, and `.bas` files to perform highly efficient, OpenMP-parallelized evaluations of electron intracules using the Cioslowski-Liu algorithm and Salvador's TFVC partitioning scheme.



### Quick Navigation
* Go to the **Modules** tab at the top to see the data structures and grid generators.
* Go to the **Source Files** tab to see the raw code.
* Go to the **User Manual** tab for instructions on running the program and input keywords.
