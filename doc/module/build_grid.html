Computes grid points for a multicenter radial integral from 0 to infinity. Radial: Gauss-Legendre. Angular: Gauss-Lebedev. Uses Becke/TFVC weights. !!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!

Computes grid points for a radial plot with manually given radiis.

Computes uniform 3D grid points for vectorial cubefile generation.

Computes uniform 3D grid points for vectorial cubefile generation with corner reference.

Computes Becke weights for each grid point and quadrature center, and stores the final weight for each point in w_beck. Implements Salvador's TFVC scheme (JCP 139, 071103 2013).
